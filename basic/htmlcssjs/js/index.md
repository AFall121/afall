# Javascript基础

JavaScript 是一种强大的编程语言，广泛用于网页开发和服务器端开发。以下是 JavaScript 的详细概括及其构成部分：

### 1. **核心语言（ECMAScript）**
   - **标准**：JavaScript 的核心由 ECMAScript 标准定义。
   - **功能**：
     - 数据类型（如字符串、数字、布尔值等）。
     - 控制结构（如 `if`、`for`、`while` 等）。
     - 函数和对象。
     - 数组、日期等内置对象。

### 2. **文档对象模型（DOM）**
   - **定义**：DOM 是浏览器提供的接口，允许 JavaScript 操作网页内容。
   - **功能**：
     - 动态修改 HTML 元素的属性、样式和内容。
     - 响应用户事件（如点击、键盘输入等）。
     - 操作页面结构（如添加、删除节点）。

### 3. **浏览器对象模型（BOM）**
   - **定义**：BOM 提供了与浏览器交互的接口。
   - **功能**：
     - 控制窗口和框架（如打开、关闭窗口）。
     - 处理浏览器历史记录。
     - 获取屏幕信息和位置信息。

### 4. **扩展库和框架**
   - **库**：如 jQuery、Lodash 等，提供便捷的功能封装。
   - **框架**：如 React、Vue、Angular 等，帮助构建复杂的前端应用。

### 5. **运行环境**
   - **浏览器端**：在浏览器中运行，提供 DOM 和 BOM 支持。
   - **服务器端**：通过 Node.js 运行，支持后端开发。
