# CSS基础

CSS（Cascading Style Sheets，层叠样式表）是一种用于定义HTML或XML（包括如SVG、MathML等扩展）文档表现的样式表语言。它的主要功能是分离文档的内容与表现形式（例如布局、颜色、字体等），从而提高内容的可访问性、代码的可维护性和跨设备的兼容性。

### CSS的主要特点：
- **分离结构和表现**：HTML负责页面结构，CSS负责页面样式。
- **重用性**：通过一个CSS文件可以控制多个网页的样式。
- **简化维护**：修改样式时只需更改CSS文件，无需逐个调整HTML文件。
- **强大的样式控制**：支持丰富的样式属性，能够精确控制页面元素的外观。

### 基本语法：
```css
选择器 {
    属性1: 值1;
    属性2: 值2;
    ...
}
```

例如：
```css
body {
    background-color: #f0f0f0;
    font-family: Arial, sans-serif;
}
```
